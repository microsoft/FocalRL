# Support

Use [GitHub Issues](https://github.com/microsoft/FocalRL/issues) for bug reports, feature requests, and questions about using FocalRL. Search existing issues before opening a new one.

For bug reports, include your environment, the command you ran, the relevant error output, and steps to reproduce the issue. Remove credentials and private data from logs before sharing them.

Report security vulnerabilities through the process in [SECURITY.md](SECURITY.md).
